# Agent Rules

1. For routine local edits (code, docs, config within this repo), proceed without stopping to ask "should I do this" — just do it.
2. Still confirm with the user before anything destructive or hard to reverse (force push, `git reset --hard`, deleting branches/files not created this session) or anything that affects shared state (pushing, opening/merging PRs, changing repo/CI settings, posting anywhere external).
