## 轉檔

`.md` 改完後產生 `.docx`：

```bash
python3 企劃文件/word-build/build_simple.py 文件/02_遊戲組對接/0828會議_待確認清單.md
```

`build_simple.py` 產彩色簡易版，`build_formal.py` 產黑白正式版（標楷體標題、新細明體內文、1.5 倍行高）。
