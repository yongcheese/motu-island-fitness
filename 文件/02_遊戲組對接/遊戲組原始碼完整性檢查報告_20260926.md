## 四、合體時需要知道的事實

1. **健身獎勵已預留串接口**：`docs/workout-rewards.md` 寫明現有健身頁（`FitnessView.tsx`）只是暫時的原型，未來由「外部健身系統」透過 API Adapter 呼叫 `reportWorkoutCompletion`，獎勵服務「一行都不用改」。這正是我們健身端與 Cloudflare 複驗接入的位置。
2. **健康頁已由遊戲組實作**：`src/components/health/` 共 9 個檔（總覽、活動紀錄、每週任務…），符合 09-24 會議「遊戲組做健康頁」的分工。
3. **技術版本**：React 19、three.js r184、Vite 6、Tailwind 4、Firebase 12、MediaPipe tasks-vision 0.10.35。我們目前是 three.js r161，合體時要升級。
4. **Firebase 專案**：`gen-lang-client-0540929973`。`firestore.rules` 31KB（09-20 更新），預設全部拒絕。
5. **後端**：`server.ts`（Express）只有商店聊天（Gemini）與 YouTube 搜尋兩個 API；沒有訓練複驗相關的後端，與先前認知一致。
6. **Motu 樣式層不在原始碼裡**：我們第一階段換皮用的 `motu-game-visual-system.css`（`@layer motu-contract`、`--motu-*` 變數）在這份原始碼中找不到，遊戲組實際用的是 Tailwind 樣式。那份 CSS 應是另外整理的設計規格檔，合體時要以原始碼的實際樣式為準再對一次。

## 五、需要提醒遊戲組的事

1. **根目錄有 136 個 `tmp-*` 暫存預覽檔**，打包說明表示這些檔案有進 git，建議日後整理。
