## 5. 過程中發現並修正的缺陷
1. **品質 gate 平滑延遲誤判**：gate 在「目標進入瞬間」採樣，因移動平均落後 raw 幾何，導致 clean 深蹲被判無效。
   → 改為在**動作峰值（最深處）取樣** gate，語意更正確，clean 全數通過。（Node 測試由 23/31 → 31/31）
2. **示範模式與 rAF 幀率耦合**：原本「一幀 synth/一次 rAF」，背景分頁節流時 60s 內幀數不足而幾乎不計次。
   → 改為**時間驅動 + 追補**，餵入確定性合成時間戳，與幀率脫鉤；背景節流下仍正確計次（實測 13s→10 次）。
3. **回退示範時相機未釋放**：相機成功但模型載入失敗會殘留串流。→ catch 中停止相機。
