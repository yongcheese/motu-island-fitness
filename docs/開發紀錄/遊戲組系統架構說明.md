**MOTU**

**遊戲網站使用者操作流程整理**

**企劃書「系統流程圖」製作參考｜User Click Flow**

| **用途：讓隊友直接依照玩家點擊順序，繪製流程節點、判斷分支與回圈。** |
| --- |

**01 遊戲代表性特色**

只保留能代表遊戲核心的特色，不展開功能規格。

| **代表特色** | **玩家感受到的玩法** |
| --- | --- |
| 運動變成遊戲進度 | 玩家完成真實動作後，得到金幣、碎片與物品獎勵。 |
| AI 與手動雙計數 | 相機可用時由 AI 計數；相機不可用時仍可點擊手動完成。 |
| 海島養成主循環 | 運動取得資源，再回島上購買、建造、換裝與互動。 |
| 可自由探索的 3D 島嶼 | 玩家移動角色，靠近建築、寵物或旅行商人後互動。 |
| 多入口但回到同一主畫面 | 建造、商店、背包、動作與轉盤完成後都回到海島。 |
| 回訪有持續動機 | 每日登入、幸運轉盤與運動紀錄讓玩家持續回來。 |

**一句話版本：玩家用真實運動換取資源，再用資源打造並探索自己的海島生活。**

**02 整體玩家流程**

這一頁可直接作為系統流程圖的主幹。

| **開啟網站 → 選擇登入方式 → 進入遊戲 → 首次進入？ → 海島主畫面 → 選擇操作 → 完成操作 → 是否繼續探索？** |
| --- |

| **節點** | **圖形** | **玩家操作** | **下一步** |
| --- | --- | --- | --- |
| U01 | 開始／結束 | 開啟遊戲網站 | 看到登入畫面 |
| U02 | 判斷／選擇 | 選擇 Google、Apple 或以訪客身分開始 | 登入遊戲 |
| U03 | 判斷／選擇 | 是否為首次進入？ | 是：進入首次引導；否：進入海島 |
| U04 | 處理 | 完成首次引導與房屋放置 | 進入海島主畫面 |
| U05 | 畫面 | 進入海島主畫面 | 可移動角色並選擇功能 |
| U06 | 判斷／選擇 | 選擇健身或一項島上操作 | 前往對應畫面／互動 |
| U07 | 處理 | 依畫面提示完成操作 | 取得結果或回饋 |
| U08 | 處理 | 關閉畫面或點擊返回 | 回到海島主畫面 |
| U09 | 判斷／選擇 | 是否繼續探索？ | 是：回到 U05；否：離開遊戲 |
| U10 | 開始／結束 | 離開遊戲 | 本次遊玩結束 |

**主循環畫法：「海島主畫面」是中心節點；每一項操作完成後都連回此節點。**

| **流程圖圖形** | **本文件中的用法** |
| --- | --- |
| 橢圓｜開始／結束 | 開啟網站、離開遊戲 |
| 長方形｜操作／畫面 | 登入、進入海島、點擊功能、完成操作 |
| 菱形｜判斷／選擇 | 首次進入？相機有權限？選哪種運動？繼續探索？ |
| 箭頭｜前往下一步 | 箭頭旁標示玩家點擊的按鈕或選擇結果 |

**03 首次進入遊戲**

只在新玩家第一次進入時展開；回訪玩家可直接前往海島。

| **順序** | **玩家看到** | **玩家點擊／操作** | **系統前往** |
| --- | --- | --- | --- |
| 1 | 開啟網站 | 等待登入畫面出現 | 選擇登入方式 |
| 2 | 登入畫面 | 點擊「使用 Google 登入」、「使用 Apple 登入」或「以訪客身分開始」 | 進入遊戲 |
| 3 | 每日登入獎勵 | 點擊領取；若未顯示則直接下一步 | 開始新手引導 |
| 4 | 教練阿肌引導 | 點擊教練／對話框繼續；也可點擊「跳過」 | 了解帳號卡、路牌、分頁、轉盤與移動 |
| 5 | 第一棟房屋提示 | 點擊「開始放置我的家」或「稍後再說」 | 分流 |
| 6A | 開始放置 | 選擇位置 → 調整方向 → 點擊確認 | 房屋完成，進入海島 |
| 6B | 稍後再說 | 關閉提示 | 直接進入海島，之後仍可再放置 |
| 7 | 海島主畫面 | 開始移動或選擇功能 | 進入主要遊玩循環 |

| **登入成功 → 首次進入？ → 是：領取每日登入 → 新手引導 → 放置房屋？ → 海島主畫面** |
| --- |

| **判斷／選擇** | **是／選項 A** | **否／選項 B** |
| --- | --- | --- |
| 是否為首次進入？ | 進入新手流程 | 直接進入海島主畫面 |
| 是否顯示每日登入？ | 點擊領取 | 跳到新手引導或海島 |
| 是否完成新手引導？ | 逐步點擊繼續 | 點擊「跳過」 |
| 是否現在放置房屋？ | 開始放置 → 確認位置 | 點擊「稍後再說」 |

**04 健身挑戰核心流程**

這是遊戲最重要的「運動 → 獎勵 → 回島」循環。

| **海島 → 點擊健身 → 選擇運動 → 相機是否取得權限？ → 動作計數 → 完成 → 查看獎勵 → 返回海島** |
| --- |

| **節點** | **玩家看到** | **玩家點擊／操作** | **下一步** |
| --- | --- | --- | --- |
| F01 | 海島主畫面 | 點擊下方「健身」 | 運動選擇畫面 |
| F02 | 開合跳／深蹲 | 點擊一種運動 | 啟動運動畫面 |
| F03 | 相機權限 | 允許或拒絕相機 | 進入對應計數方式 |
| F04-A | AI 相機計數 | 將全身放入畫面並跟著示範動作 | 系統自動累計次數 |
| F04-B | 手動點擊計數 | 每完成一次，點擊「我完成了一次動作！」 | 系統手動累計次數 |
| F05 | 運動進度 | 持續動作；完成後點擊右上角結束 | 成果畫面 |
| F06 | 挑戰成功 | 查看總次數、金幣與碎片；可點選慶祝動作 | 準備返回 |
| F07 | 成果畫面 | 點擊「返回我的海島」 | 回到海島主畫面 |
| F08 | 首次運動獎勵（若出現） | 點擊「收下」 | 獎勵存入背包，繼續探索 |

| **必要判斷菱形** | **是** | **否** |
| --- | --- | --- |
| 相機是否取得權限？ | AI 相機計數 | 手動點擊計數 |
| 選擇開合跳？ | 進入開合跳 | 進入深蹲 |
| 是否完成／結束運動？ | 顯示成果與獎勵 | 繼續計數 |
| 是否出現首次運動獎勵？ | 點擊「收下」 | 直接回到海島 |

**05 海島主畫面操作分支**

這些分支是平行選項；玩家不需要依序全部完成。

| **分支** | **玩家如何進入** | **點擊順序** | **完成後** |
| --- | --- | --- | --- |
| 建造 | 點擊左側「建造」 | 選物件 → 放到島上 → 旋轉／調整 → 確認或取消 | 返回海島 |
| 商店 | 點擊左側「商店」 | 選分類 → 選商品 → 購買／套用 → 關閉 | 返回海島 |
| 背包 | 點擊左側「背包」 | 選擁有的物品 → 穿上／使用／套用 → 關閉 | 返回海島 |
| 角色動作 | 點擊左側「動作」 | 選擇動作或表情 | 角色播放動作後留在海島 |
| 建築／寵物 | 移動並靠近目標 → 點擊提示或按 E | 進入建築、撫摸或餵食寵物 | 完成後返回海島 |
| 旅行商人 | 移動到商人旁 → 點擊提示或按 E | 瀏覽限時商品 → 購買或關閉 | 返回海島 |
| 幸運轉盤 | 點擊右下角轉盤 | 確認使用抽獎券 → 轉動 → 查看結果 → 關閉 | 返回海島 |
| 追蹤 | 點擊下方「追蹤」 | 查看運動次數、卡路里與近期紀錄 → 關閉 | 返回海島 |
| 設定 | 點擊下方「設定」 | 調整設定 → 關閉 | 返回海島 |

**建議畫法：從「海島主畫面」接一個菱形「玩家要進行哪一種操作？」；各分支只畫入口、核心點擊與返回海島三段。**

| **海島主畫面 → 選擇一項操作 → 完成／關閉 → 回到海島主畫面 → 是否繼續探索？ → 否：離開遊戲** |
| --- |

**06 流程圖交付檢查**

畫完流程圖後，用這六點快速確認內容是否完整且仍維持精簡。

| **交付前檢查** | **判定** |
| --- | --- |
| 每個箭頭都能說出玩家點了什麼或做了什麼 | 必要 |
| 首次進入流程與回訪流程已分開 | 必要 |
| AI 計數與手動計數由相機權限分流 | 必要 |
| 所有島上分支完成後都連回海島主畫面 | 必要 |
| 流程最後有「是否繼續探索？」與「離開遊戲」 | 必要 |
| 追蹤、設定不展開內部功能 | 保持精簡 |
