# 筆電方向鍵與觸控板控制修復

驗證日期：2026-11-03。工作目錄：`育秀杯-健身wt`，分支：`健身`。

## 操作

- 移動：WASD 或方向鍵；中文鍵盤配置仍以實體 WASD 位置判斷。
- 一般走動：按住觸控板主按鍵拖曳，或滑鼠右鍵拖曳，轉動視角。
- 建造／室內佈置：Option（Windows 為 Alt）＋主按鍵拖曳轉動視角；普通拖曳保留給物件。
- 縮放：觸控板雙指上下滑動、瀏覽器提供的捏合手勢，或滑鼠滾輪。純水平滑動不改縮放。
- 輸入文字、操作輸入框方向鍵及瀏覽器快捷鍵不會帶動人物。切換視窗會清掉按住的方向鍵。

## 修復依據

原本人物只接受 WASD，方向鍵僅有鏡頭監聽；一般鏡頭只綁定右鍵拖曳。滾輪縮放按事件次數固定加減，讓觸控板拆成許多微小事件的手勢被放大。

新增共用鍵盤與縮放轉換，依移動量處理縮放，並將鏡頭滾輪監聽限制在 Canvas。滑鼠／觸控板回報沒有按住任何按鍵時，解除尚未結束的物件拖曳擷取，避免後續 HUD 點擊被持續導向場景。macOS 的 Control-click 與編輯模式的 Option-drag 不會啟動家具拖曳。

## 驗證

瀏覽器使用獨立 context、`http://127.0.0.1:3001`、自行建立的本機測試訪客，並阻擋 Firebase 網路請求；未使用展示帳號。伺服器從此 worktree 啟動 Vite。此網址為控制測試用，未掛載 Express API。
