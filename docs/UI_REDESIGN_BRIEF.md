# UI/UX 重新設計需求（Stitch）— 決策記錄

> 用 Google Stitch MCP 設計更貼近使用者的 UI/UX，落地回現有純前端 App。
> 此檔在「重啟 Claude Code 載入 Stitch 工具」後仍保留，回來說「用 Stitch 開始做 UI」即可接續。

## 使用者選定方向（2026-06-15）
| 項目 | 決定 |
|------|------|
| 設計範圍 | **全部四個分頁**（島嶼/訓練/健康/設定）。島嶼維持 3D 場景，Stitch 設計其**疊加 UI**（左側功能列、商店、HUD、頂部狀態、底部 tab） |
| 視覺風格 | **由 Stitch 自由發揮**（但需與 3D 卡通島嶼／DEMO PPT 調性協調，不要互打架） |
| 展示裝置 | **響應式全裝置**（手機直式 / 平板 / 筆電桌機 皆需美觀） |
| 語氣／受眾 | **遊戲感強**（任務、獎勵、等級、進度感；像高品質手遊） |

## 必須保留的功能契約（落地時不可破壞）
- 四大分頁與導覽（島嶼/訓練/健康/設定），底部 tab bar。
- 訓練核心流程：分類 → 動作清單 → 動作簡介（暖身開關/示意動畫）→ 即時偵測（相機 + 三色身體疊圖 + 倒數邊框 + HUD：暫停/退出/時間/次數/卡路里/倒數/語音/BGM）→ 結算（有效/無效次數、達標率、卡路里、金幣、S/A/B/C 評級、常見錯誤）。
- 金幣防刷鐵則：金幣只由 `store.commitSession()` 產生；島嶼只能 `store.spendCoins()`。
- 既有模組契約見 docs/CONTRACTS.md，store API 不變。
- 核心引擎/測試（31/31 綠）不可動，UI 只换皮與互動。

## Stitch 執行計畫（重啟後）
1. 用 Stitch 針對 4 個分頁各產出 UI（響應式、遊戲感）：
   - 島嶼：頂部玩家狀態（頭像/等級/XP/金幣）、左功能列、右縮放、商店 bottom sheet、成就、放置操作列。
   - 訓練：菜單（搜尋+分類 chips+動作卡）、動作簡介、即時偵測 HUD、結算（評級動畫）。
   - 健康：摘要卡 + 圖表（本週vs上週、時長、卡路里、達標率、錯誤分布）+ 最近紀錄。
   - 設定：帳號/個人資料/目標/偏好/隱私/關於。
2. 取得 Stitch 輸出（設計稿/HTML/CSS）→ 萃取設計語言（色票、圓角、字級、元件樣式）。
3. 落地：更新 `app/styles/app.css`（設計 token + 元件）與各 feature 的 .css/.js 結構，保持契約不變。
4. 用 Preview 驗證四頁 + 訓練示範模式，截圖比對。

## 重啟步驟（給使用者）
1. 結束目前 Claude Code（關閉視窗 / 輸入 `/exit`）。
2. 重新開啟 Claude Code（回到此專案資料夾）。
3. 輸入一句：「**用 Stitch 開始做 UI**」即可接續本計畫。
