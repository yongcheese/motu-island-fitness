# OVERALL REVIEW — Gate 7

對整合後系統做整體審查。結論：**通過**，可丟給評審。

## 1. 契約一致性
- 四個 feature 皆遵守 `{ id, label, icon, mount(root,ctx), unmount() }` 契約；只透過 `store` 公開 API 與 `core` 互動。✓
- 金幣防刷鐵則落實：全程僅 `store.commitSession()` 能加幣；island 只 `spendCoins`；UI 無任何直接加幣路徑。瀏覽器實測：訓練結算後錢包 80→838、Lv 1→3，島嶼可消費。✓
- import 路徑全部正確，模組圖在瀏覽器成功載入（無 404、無 module error）。✓

## 2. 核心引擎（最關鍵）
- 31 項 Node eval 全綠，且**在瀏覽器以相同模組重跑結果一致**（clean→5V、cheat→0V/5I）。✓
- 標準化層驗證：scale 1.5×/0.7×、平移 dx 0.12 下計次不變 → 證明「不同身形/鏡頭遠近一致判定」此核心賣點為真。✓
- 六層防作弊覆蓋：完整週期、信心值（遮擋→暫停）、防抖（雜訊不暴衝）、單肢/同步（開合跳手腳）、代償（彎腰/塌腰/坐姿）、動態冷卻（250ms 內雙觸只計一次）。✓
- 品質 gate 採「峰值取樣」修正了平滑延遲造成的誤判（見 TRACE 缺陷#1）。✓

## 3. 即時體驗（瀏覽器實測截圖佐證）
- 三色骨架依部位上色、隨深度由黃轉綠；倒數光環顏色同步當前狀態（紅/黃/綠）。✓
- HUD：有效次數（達標金色跳動）、時間、kcal、倒數；控制：語音/BGM/暫停。✓
- 結算：S/A/B/C 評級環、有效/無效、達標率、金幣、常見問題清單。✓
- 分級語音教練具搶佔＋去重＋冷卻；無 Web Speech 時靜默降級為字幕。✓

## 4. 健壯性 / 邊界
- 無相機/權限被拒 → 自動「示範模式」，且**改為時間驅動＋追補**，與 rAF 幀率脫鉤，背景分頁節流下仍正確計次（見 TRACE 缺陷#2）。✓
- 相機失敗回退時釋放相機串流（修正資源殘留）。✓
