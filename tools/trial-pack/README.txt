Motu 島嶼健身｜試玩包（Windows）
================================

【怎麼開】
1. 先把整個壓縮檔「解壓縮」到任一資料夾（不要在壓縮檔裡直接點）。
2. 點兩下 Start-Motu.bat。
3. 會出現一個黑色視窗，瀏覽器會自動打開遊戲（網址是 http://localhost:5180 ）。
   如果 5180 被占用，會自動改用下一個號碼，黑色視窗裡會顯示實際網址。
4. 進到健身頁時，瀏覽器會詢問是否允許使用相機，請按「允許」。
   建議用 Chrome 或 Edge。

【怎麼關】
關掉那個黑色視窗就好。

【可能遇到的狀況】
- 跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
  這是因為 .bat 是從網路下載的，不是病毒。
- 黑色視窗說找不到 Node.js：請到 https://nodejs.org/ 安裝 LTS 版，再點一次。
- 瀏覽器沒有自己打開：手動開啟黑色視窗裡顯示的網址。
- 相機打不開：確認網址是 localhost 開頭（不能改成電腦的 IP），
  且沒有其他程式（視訊會議、相機 App）正在占用相機。

【試玩包沒有的功能】
下面三項需要伺服器金鑰，試玩包沒有附，使用時會顯示錯誤，屬於正常現象：
- 商店聊天（AI 店主）
- 音樂的 YouTube 歌名搜尋（直接貼 YouTube 連結是在瀏覽器解析，不需要伺服器）
- 每日登入領獎

【請注意】
- 登入與存檔會寫進你們自己的 Firebase 專案，跟平常開發用的是同一個資料庫。
- 健身的姿勢辨識（MediaPipe）完全在瀏覽器裡執行，相機畫面不會上傳。

【回報】
能不能順利開起來、哪一步卡住，請直接截圖黑色視窗和瀏覽器畫面給健身組。
