# 中文摘要

隨著居家健身與自主運動訓練模式的快速普及，越來越多使用者在缺乏專業教練即時指導的情況下進行運動。然而，此類訓練方式容易產生姿勢不正確、動作幅度不足、身體代償以及重複次數誤判等問題，進而影響訓練成效與運動安全性。此外，居家運動環境普遍缺乏足夠的互動性與回饋機制，使得使用者難以維持長期且穩定的運動習慣。目前市面上多數健身應用程式主要著重於動作次數統計功能，對於動作品質的驗證能力有限，亦缺乏能夠有效提升使用者持續參與意願之激勵機制。

為解決上述問題，本研究提出「AI 健身辨識與島嶼建設連動系統（AI Fitness Recognition and Island Construction Linked System）」，透過整合電腦視覺技術與遊戲化設計理念，建構兼具動作品質監測、即時矯正回饋與長期激勵效果之智慧健身平台。

在健身動作辨識方面，本系統僅需搭配一般消費級攝影設備，即可利用 MediaPipe Pose 技術即時擷取人體 33 個骨架關鍵點資訊。系統進一步結合五層判斷架構（Five-Layer Judgment Architecture）、動作有限狀態機（Motion Finite-State Machine）以及六層防作弊機制（Six-Layer Anti-Cheating Mechanism），針對動作完整性、動作深度及代償行為進行多層次驗證，確保僅有符合標準之訓練動作得以被認定為有效次數。此外，系統透過三色視覺提示與優先級語音回饋機制，即時提供動作修正建議；並藉由人體幾何正規化技術（Body Geometry Normalization），降低使用者體型差異及攝影距離變化所造成之判斷誤差，以提升辨識結果之穩定性與一致性。

在遊戲化應用設計方面，本研究創新導入互動式島嶼建設平台作為運動成果視覺化之呈現載體。透過與健身辨識系統之間的資料連動機制，使用者於運動過程中所產生之訓練數據，僅能在通過 AI 品質驗證後轉換為遊戲資源，藉此建立以正確運動行為為基礎之遊戲進程模式，避免單純透過重複計數而獲取遊戲獎勵之情形。

在虛擬經濟與島嶼發展機制方面，使用者需透過高品質且符合規範之訓練動作獲取遊戲金幣，並將其投入於島嶼擴建、建築升級及景觀配置等項目。此設計將原本抽象且不易量化之運動成果轉化為具體且可視化之成長歷程，使使用者能於持續訓練過程中獲得即時回饋與累積性成就感，進而形成「運動訓練、成果回饋、島嶼建設、持續訓練」之正向循環。

本研究之核心創新在於突破傳統健身系統僅著重於動作計數之限制，進一步導入動作品質驗證與遊戲化激勵機制，兼顧運動成效、使用者體驗及長期參與動機。未來系統預計支援十項主流健身動作辨識，並以最低硬體門檻提供接近專業教練等級之智慧化運動指導服務，期望有效提升居家健身之訓練品質與使用者黏著度，進而促進全民健康管理之發展。

關鍵詞：AI應用、電腦視覺、MediaPipe Pose、即時動作矯正、遊戲化設計、健康科技。

# Abstract

With the rapid growth of home fitness and self-directed training, users often exercise without professional supervision, frequently leading to incorrect postures, half-range motions, compensatory movements, and inflated repetition counts. Furthermore, the monotonous nature of home workouts often results in a lack of long-term motivation. Most existing fitness apps only count repetitions, failing to verify movement quality or provide sustained interactive incentives.

To address these issues, this proposal presents an "AI Fitness Recognition and Island Construction Linked System" that integrates computer vision with gamification mechanisms. On the fitness image recognition front, the system utilizes a single consumer-grade camera and MediaPipe Pose to extract 33 skeletal landmarks in real time. It applies a five-layer judgment architecture, a motion finite-state machine, and a six-layer anti-cheating mechanism to ensure that only complete, sufficiently deep, and compensation-free repetitions are validated. Real-time correction is delivered via a tri-color visual indicator and prioritized voice coaching, while body-geometry normalization ensures consistent judgment across different body types and camera distances.

Regarding the **game concept and positioning**, the system innovatively incorporates an interactive island construction website for "fitness result visualization". Through a rigorous **linkage mechanism with the fitness system**, AI-verified training data is converted into virtual resources, ensuring that the game's progression is built strictly on "correct movements". Within the **coin economy and island construction** design, users earn coins exclusively through high-quality exercises and invest them in expanding and upgrading their virtual island. This transforms abstract workouts into a long-term achievement process, creating a positive loop of "training, feedback, construction, and retraining".

The core innovation lies in shifting the focus from mere "counting" to "quality verification and motivation enhancement". Planned to support ten mainstream exercises, this system aims to bring near-coach-level intelligent guidance and high-retention gamified interactive experiences into every home at the lowest possible hardware barrier. This document represents the planning and design stage of the project.

**Keywords:** AI Application, Computer Vision, MediaPipe Pose, Real-time Correction, Gamification, Health Technology.

# 前言

運動不足已是不容忽視的公共健康課題。世界衛生組織指出，身體活動不足已成為影響全球死亡率的第四大危險因子；而依行政院體育委員會運動城市調查，國人無規律運動習慣的比率一度高達 72.2%。世界衛生組織並建議成年人每週至少進行 150 分鐘中等強度或 75 分鐘高強度有氧運動，並搭配每週兩次以上的肌力訓練。

後疫情時代，越來越多人改以居家、自主的方式運動，行動裝置上的健身 App 與線上課程使用量大幅成長。然而居家訓練缺乏教練在旁即時把關，使用者常做出半程、代償或作弊動作，不但練不到效果，還可能累積成運動傷害。現有 App 多半只能「計時、計次」，無法判斷「動作做得對不對」。

本作品即是針對這個缺口提出的構想：我們打算用一支家裡就有的手機，結合 AI 姿態辨識，把「教練的眼睛」帶進每一次居家訓練。本企劃書屬於規劃與設計階段的提案，以下說明我們規劃的系統概念、核心技術、動作判定規格、即時矯正機制，以及預計分階段實作的開發時程與預期成效。

# 第一章　專案緣起與創意亮點

## 1.1　問題痛點

根據世界衛生組織建議，成年人每週應進行至少 150 分鐘中等強度或 75 分鐘高強度有氧運動，並搭配每週兩次以上的肌力訓練。後疫情時代，越來越多人改在家自主訓練，但居家訓練最大的瓶頸不是「動作種類」，而是「品質確認」。在無人監督下，使用者常出現三類問題：動作只做半程、用代償肌群完成動作、以及為衝次數而草率甚至晃動身體作弊。

既有居家健身 App 多以計時計次為核心，僅靠加速度計或簡單影像判斷次數，缺乏對「動作品質」的判定，使用者練了卻不知道自己做得對不對。這正是本作品要解決的痛點。

## 1.2　呼應競賽主題：AI 智慧應用

育秀盃近年聚焦「AI 智慧應用大未來」。本作品正是以人工智慧與電腦視覺為核心的健康科技應用：透過 AI 姿態辨識把「專業教練的眼睛」數位化，讓 AI 在家庭場景中即時判讀動作品質並給予矯正，呼應以 AI 改善生活、促進全民健康的競賽精神。

## 1.3　創新亮點

品質導向：業界多數只計次，本系統定義「有效次數」必須同時滿足完整週期、達標深度與無代償，真正確認訓練品質。

人體幾何標準化：以肩寬、腿長等比例建立判定門檻，讓不同身形、鏡頭遠近的使用者都得到一致判定，是本系統最關鍵的技術差異化。

零額外硬體：只需一支手機、平板或電視鏡頭，無須穿戴裝置，硬體門檻最低、最易普及。

即時雙模回饋：紅／黃／綠三色號誌搭配分級語音，使用者就算分心也能用餘光與聽覺即時修正。

可延伸性：同一套動作完整性判定可延伸到復健、長照與校園體適能，應用想像空間大。

# 第二章　系統概念與運作流程

## 2.1　設計理念：不是計次，而是品質確認

本系統將「有效次數」定義為同時滿足三項條件的動作：完成完整週期（起始→發力→達標→回復）、達到標準深度（如髖部低於膝蓋）、姿勢無顯著代償（如塌腰、撅臀、身體後仰）。三大設計支柱為精準判別、安全防線與數據輸出。

## 2.2　系統架構：五層判定防線

系統以分層架構確保判定的精準與穩定，其中標準化層為本系統的關鍵設計。

|  |  |  |
| --- | --- | --- |
| **層級** | **名稱** | **主要職責** |
| 01 | 輸入層 | 畫面輸入、光線校準、多人狀態排除。 |
| 02 | 辨識層 | 節點座標擷取、信心值過濾、部位入鏡檢查。 |
| 03 | 標準化層 | 依肩寬、腿長比例建立動態判定門檻，確保不同身形之判定一致性（系統關鍵層）。 |
| 04 | 邏輯層 | 動作狀態機、防弊檢查、計次冷卻邏輯。 |
| 05 | 互動層 | 三色回饋、語音教練、訓練結算報告。 |

## 2.3　動作狀態機：完整週期才計次

|  |  |  |
| --- | --- | --- |
| **階段** | **名稱** | **判定條件與意義** |
| 1 | 起始姿勢 | 確認站姿、地面姿勢穩定，作為動作週期的起點與終點。 |
| 2 | 發力階段 | 偵測關鍵節點朝目標方向移動，視為動作開始進行。 |
| 3 | 達標階段 | 角度或距離達到標準閾值，系統亮綠燈，並暫不計次。 |
| 4 | 回復階段 | 回到起始姿勢，避免使用者於底部停留而重複計次。 |
| 5 | 完成計次 | 整個週期完整且無代償，方納入有效訓練報告。 |

# 第三章　核心技術與可行性

## 3.1　核心輸入：MediaPipe Pose

系統以 Google 開源的 MediaPipe Pose 作為輸入核心，可即時擷取人體 33 個骨架關鍵點的 X／Y／Z 座標與可見度（信心值），並能在中階手機上以每秒 30 影格以上的速度執行。選用此方案的理由是低延遲、跨平台、免額外硬體，非常適合居家即時應用，技術成熟、可行性高。系統支援正面、側面與 45° 視角輸入，使用者可依場地彈性擺放鏡頭。

## 3.2　關鍵創新：人體幾何標準化

若以絕對像素距離當判定門檻，鏡頭遠近與身材差異會造成嚴重偏差。本系統改採「比例式門檻」：水平方向以肩寬為比例尺（例如開合跳的「腳超肩寬」以肩寬 1.0～1.2 倍為門檻），垂直方向以軀幹或腿長為比例尺（例如高抬腿以髖部 Y 座標為基準）。此設計讓系統在不同身形與距離下都維持一致準確率，是本系統最核心的技術貢獻。

## 3.3　規則式狀態機的優勢

相較於端到端深度學習模型，本系統採用規則式狀態機作為判定核心，原因有三：可解釋性高，方便針對個別動作微調參數；運算負擔輕，能在低階裝置即時執行；以及容易與防作弊、信心值過濾等模組整合。這讓作品在競賽期程內具備高度可實作性。

# 第四章　動作判定規格

本系統首期規劃支援十項主流健身動作，分為五大群組，每組皆設判定關鍵與防作弊重點。

|  |  |  |
| --- | --- | --- |
| **動作名稱** | **判定關鍵（有效）** | **防作弊重點** |
| 深蹲 / 弓箭步 | 髖部低於膝蓋高度，起身回穩。 | 排除只彎腰、半蹲、坐椅假動作。 |
| 開合跳 / 高抬腿 | 手過肩 + 腳超肩寬 / 膝蓋達髖高。 | 排除只揮手、只張腳、坐著抬腿。 |
| 伏地挺身 / 波比跳 | 手肘下壓達標，全身維持一直線。 | 排除塌腰、撅臀、省略棒式流程。 |
| 仰臥起坐 / 捲腹 | 軀幹抬起角度達標、背部確實離地。 | 排除只抬頭、手部甩動代償。 |
| 臀橋 / 側弓步 | 髖部上推成線 / 橫向跨距與深度。 | 排除只抬腿不推髖、橫移不蹲。 |

# 第五章　即時矯正與使用者體驗

## 5.1　三色視覺反饋

|  |  |  |
| --- | --- | --- |
| **顏色** | **意義** | **觸發條件** |
| 紅色 | 姿勢錯誤或無效 | 姿勢錯誤、關鍵節點遺失、動作完全無效。 |
| 黃色 | 接近達標 | 方向正確但深度不足、穩定性不夠。 |
| 綠色 | 達標 | 目前階段達標，可進入下一動作流程。 |

## 5.2　分級語音提示

|  |  |  |
| --- | --- | --- |
| **優先級** | **觸發類別** | **典型提示語句** |
| 高 | 看不到全身、姿勢危險（塌腰等） | 「請後退一步，我看不到您的腳。」「請保持背部平直，避免塌腰。」 |
| 中 | 動作深度不足、身體歪斜 | 「再蹲深一點。」「身體保持中線。」 |
| 低 | 節奏提示、接近達標鼓勵 | 「節奏穩定，繼續保持！」「再一下就到了！」 |

高優先級提示具搶佔機制，可中斷低／中優先級語句，確保安全訊息不被掩蓋。

## 5.3　六層防作弊與誤判控制

|  |  |  |
| --- | --- | --- |
| **層級** | **名稱** | **功能說明** |
| 1 | 完整週期 | 起始 → 發力 → 達標 → 回復，缺一階段皆不計次。 |
| 2 | 信心值檢查 | 膝蓋遮擋、手腕不清楚或多人入鏡時暫停判定。 |
| 3 | 防抖處理 | 平滑濾波與連續幀確認，防止瞬間座標跳動誤判。 |
| 4 | 單肢偵測 | 檢查開合跳、波比跳等上下肢是否同步運作。 |
| 5 | 代償偵測 | 辨識只彎腰、塌腰、身體後仰等常見代償動作。 |
| 6 | 動態冷卻 | 計次後加入短暫冷卻時間（約 250～500 ms），避免底部抖動重複計次。 |

# 第六章　訓練結算與數據價值

訓練結束後，系統以代謝當量（METs）模型估算熱量，公式為 kcal = MET × 體重(kg) × 時間(hr)。各動作之 MET 值採用國際《Compendium of Physical Activities》所訂定之標準值，例如徒手深蹲（緩慢且控制）為 5.4 MET、費力的徒手健身操（伏地挺身、開合跳、仰臥起坐等）為 8.0 MET。以徒手深蹲為例，體重 70 公斤的使用者連續訓練 10 分鐘（0.167 小時），熱量消耗為 5.4 × 70 × 0.167 ≈ 63 大卡；系統並會依實際達標率與動作強度權重調整計算，避免高估半程動作的耗能。

系統會自動產生結構化報告，內容包含有效／無效次數、姿勢達標率、動作強度權重分析、常見錯誤姿勢紀錄，以及綜合 S／A／B／C 訓練評級。報告可保存於本機或雲端，供長期追蹤與個人化課表建議之用，也讓「進步」變得看得見、可量化。

# 附錄 B　島嶼遊戲整合（與健身系統連動）

## B.1　遊戲概念與定位

### 定位核心：把健身成果變成島嶼成長

本遊戲定位為「健身成果可視化」的島嶼建設型遊戲，核心目的不是取代健身系統本身，而是把原本抽象的運動次數、達標率與訓練紀錄，轉化為玩家看得見、能累積、可持續經營的島嶼成長。使用者每完成一次有效訓練，就能讓島嶼獲得資源與建設進度，使運動不再只是單次任務，而是逐步推進的長期養成。

### 產品分工：AI 判定品質，遊戲維持動機

在整體產品中，健身影像辨識系統負責判斷「動作是否正確」，島嶼遊戲則負責回答「為什麼要持續做」。兩者分工明確：AI 系統提供可信的運動判定，遊戲系統提供情境、目標與回饋。透過這種設計，使用者不只是在完成深蹲、開合跳或其他訓練動作，而是在用正確運動累積自己的島嶼成果。

**圖 B-1　遊戲定位四層價值**

|  |  |  |  |
| --- | --- | --- | --- |
| **動機延伸層** | **成果視覺化** | **低門檻留存** | **差異化定位** |

### 使用情境：低壓、輕量、可長期累積

此遊戲採用低門檻、輕量化、可長期累積的設計方向，適合學生、居家健身者與缺乏固定運動習慣的使用者。相較於高操作壓力或重競技的遊戲形式，島嶼建設更適合與健身系統結合，因為它不要求使用者長時間盯著遊戲操作，而是把注意力保留在運動本身，並在訓練結束後提供成果回饋。

### 視覺成果：努力可以留下痕跡

遊戲概念的重點在於「努力可以留下痕跡」。玩家初期擁有一座基礎島嶼，隨著訓練次數增加，可逐步建造房屋、道路、植栽、公共設施與裝飾物件。島嶼的變化象徵使用者的健康行為累積，也讓運動成果從數字報表延伸為具情感連結的視覺成就。

### 整體定位整理

本遊戲的定位可歸納為三項：第一，作為健身系統的動機延伸層，提升使用者持續訓練的意願；第二，作為訓練成果的視覺化載體，讓進步更容易被感受；第三，作為產品差異化設計，使本作品不只是 AI 健身工具，也具備互動娛樂與長期留存的應用價值。

## B.2　與健身系統的連動機制

### 資料基礎：由 AI 訓練結算驅動遊戲

島嶼遊戲與健身系統的連動基礎，是前述 AI 動作判定所產生的訓練資料。系統每次訓練結束後，會將有效次數、動作種類、訓練時長、達標率、錯誤姿勢次數、熱量估算與任務完成狀態整理為結算結果，再交由遊戲模組轉換為金幣、經驗值或建設進度。

**圖 B-2　健身系統與島嶼遊戲連動流程**

|  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **1 選擇訓練任務** | **→** | **2 AI 姿態辨識** | **→** | **3 訓練結算** | **→** | **4 獎勵轉換** | **→** | **5 島嶼建設** |

### 防刷機制：只有有效動作才能產生獎勵

為避免遊戲獎勵被任意刷取，金幣不以單純晃動身體或點擊按鈕取得，而是必須通過健身影像辨識系統的有效動作判定。也就是說，只有完成完整週期、達到標準深度且沒有明顯代償的動作，才會計入遊戲獎勵。這使遊戲經濟直接建立在「正確運動」之上，而不是建立在表面次數之上。

### 操作流程：訓練—回饋—建設—再訓練

實際流程可分為五個步驟：使用者先選擇訓練任務，系統開啟鏡頭並進行動作辨識；訓練過程中，AI 以紅／黃／綠視覺回饋與語音提示協助修正姿勢；完成後，系統產生訓練結算；遊戲模組根據結算資料發放金幣與任務獎勵；最後，使用者可將金幣投入島嶼建設，形成「訓練—回饋—建設—再訓練」的循環。

**表 B-1　訓練資料到遊戲獎勵的轉換規則**

|  |  |  |
| --- | --- | --- |
| **訓練資料** | **遊戲轉換** | **設計目的** |
| 有效次數、動作種類 | 基礎金幣與經驗值 | 確保每次獎勵來自實際完成的正確訓練。 |
| 達標率、錯誤姿勢次數 | 品質加成或獎勵降低 | 鼓勵使用者追求標準動作，而非單純衝次數。 |
| 訓練時長、任務完成狀態 | 每日任務與週目標進度 | 把運動行為轉成可追蹤的長期遊戲目標。 |
| 去識別化結算資料 | 同步遊戲進度 | 降低原始影像依賴，兼顧隱私與資料可用性。 |

### 品質導向：獎勵反映訓練品質

此連動機制的設計重點，是讓遊戲獎勵反映訓練品質，而非只反映訓練時間。舉例而言，同樣完成二十次深蹲，若使用者動作完整、達標率高且錯誤姿勢少，系統可給予較高金幣或額外獎勵；若動作半程、姿勢不穩或出現作弊計次，則降低獎勵甚至不計入有效成果。如此可鼓勵使用者追求正確動作，而不是單純追求速度或次數。

### 任務延伸：每日任務與週目標

此外，連動機制也可支援每日任務、週目標與連續訓練獎勵。例如完成指定動作組合可獲得建設材料，連續達成每週目標可解鎖新的島嶼區域。這些任務不只提升遊戲性，也能回到健康目的：引導使用者養成規律、適量且安全的運動習慣。

### 資料原則：遊戲端接收結算，不直接保存原始影像

在資料設計上，遊戲端只需接收經系統整理後的訓練結果，不必直接存取原始影像。這能降低資料處理負擔，也有助於隱私保護。未來若進一步開發帳號同步功能，使用者可在不同裝置延續訓練紀錄與島嶼進度，使健身與遊戲成果形成一致的個人化體驗。

## B.3　金幣經濟與島嶼建設

### 經濟定位：金幣連接運動努力與建設成果

金幣是島嶼遊戲的主要經濟單位，扮演「運動努力」與「建設成果」之間的轉換媒介。使用者透過有效訓練取得金幣，再將金幣投入建築、裝飾、土地擴張與設施升級，使每一次正確運動都能累積成具體可見的島嶼變化。

### 金幣來源：基礎獎勵與品質加成

金幣來源可分為基礎獎勵與加成獎勵。基礎獎勵來自完成有效動作與訓練任務，確保只要使用者確實運動就能得到穩定回饋；加成獎勵則可依達標率、連續訓練天數、任務難度與動作品質給予額外金幣。此設計能兼顧新手友善與進階挑戰，避免初期門檻過高，也保留長期進步空間。

**表 B-2　金幣經濟模型整理**

|  |  |  |
| --- | --- | --- |
| **機制類型** | **觸發條件／用途** | **作用** |
| 基礎獎勵 | 有效動作、訓練任務 | 穩定給予金幣，維持新手回饋。 |
| 品質加成 | 達標率、錯誤姿勢少 | 鼓勵標準動作與安全訓練。 |
| 連續獎勵 | 每日任務、週目標 | 引導規律運動，避免一次性使用。 |
| 建設消耗 | 建築、裝飾、土地、升級 | 把金幣轉成可見的島嶼成長。 |
| 經濟控制 | 獎勵上限、任務節奏 | 避免刷幣與過度運動。 |

### 建設層級：從基礎島嶼到主題區域

金幣消耗則以島嶼建設為核心。初期可先開放基礎建築與簡單裝飾，例如小屋、道路、樹木與休憩設施；中期可解鎖功能性建物與主題區域，例如健身廣場、能量塔、花園、碼頭或訓練中心；後期則可提供土地擴張、建築升級與稀有外觀，使島嶼從單一場景逐步成長為完整空間。

### 平衡機制：避免刷幣與過度運動

為維持遊戲經濟的公平性與可持續性，金幣設計不宜完全無上限累積，而應搭配每日任務、週目標、品質加成與適度獎勵上限。這樣可以避免使用者為了刷金幣而過度運動，也能讓遊戲回到健康促進的目的。系統應鼓勵規律訓練，而不是鼓勵短時間大量衝刺。

### 健康象徵：島嶼作為努力歷程的視覺紀錄

島嶼建設除了提供裝飾與成就感，也能作為健康進度的象徵。例如連續運動七天可解鎖紀念建築，累積完成特定動作可開放對應主題區域，達成週目標可獲得特殊裝飾。透過這種方式，島嶼不只是遊戲畫面，而是使用者健康習慣與努力歷程的視覺化紀錄。

### 正向循環：健康管理、AI 技術與遊戲化體驗整合

整體而言，金幣經濟與島嶼建設的設計目標，是建立一個正向循環：正確訓練帶來金幣，金幣推動島嶼成長，島嶼成長提升使用者成就感，進而提高再次訓練的動機。此循環能補足一般健身工具容易缺乏長期吸引力的問題，使本作品兼具健康管理、AI 技術應用與遊戲化體驗三項價值。
